# RED SOL - Mars Outpost Trainer
Team RezonX Elites - NASA Space Apps Challenge 2026 ("Build a Junior Astronaut Mission Trainer").

Run a small Mars outpost in 3D. Face dust storms, solar radiation surges, space rocks and broken machines. Every choice helps one thing and costs another.

## Play
- Desktop: WASD move, Shift run, hold E/Space to work, drag mouse to look, Esc pause.
- Phone (landscape): joystick, USE, RUN, swipe right side to look.
- Works offline after the first load. Progress is saved in localStorage.

## Develop
    npm install
    npm run dev          # local dev server
    npm run build        # static site in dist/ (works on GitHub Pages, base './')
    npm run test:sim     # headless simulation tests (bots, determinism, balance)

Structure: src/sim (pure game logic, no DOM), src/world (Three.js scene, characters, effects), src/ui (screens), src/systems (input, audio, save), src/data/archive.js (archived NASA facts).
Browser tests (need Edge/Chrome + `npm run preview`): tests/flow.mjs, tests/e2e.mjs, tests/misc.mjs.
